**Spelling Star** - Practice spelling words as a fun, interactive game! 

A simple, kid-friendly web application to help children practice their spelling words through gamification.

## ✨ Features

- 🎮 **Game-based learning** - Makes spelling practice fun!
- 🎯 **Custom word lists** - Add your own spelling words
- 🔊 **Audio feedback** - Hear each word pronounced (text-to-speech)
- ⭐ **Star rewards** - Earn stars for correct answers
- 📱 **Mobile-friendly** - Works on tablets and phones
- 💾 **Progress tracking** - See your improvement over time

## 🚀 Quick Start

### Option 1: Use GitHub Pages (Easiest)

Visit: [https://bagg3rs.github.io/spelling-star/](https://bagg3rs.github.io/spelling-star/)

### Option 2: Run Locally

```bash
# Clone the repository
git clone https://github.com/bagg3rs/spelling-star.git
cd spelling-star

# Open in your browser
open index.html
```

No build steps or dependencies required - it's just HTML, CSS, and JavaScript!

## 🎯 How to Use

1. Click **"Start Practice"**
2. Listen to the word (click the speaker icon to hear it again)
3. Type the spelling
4. Get instant feedback and earn stars!
5. Track your progress over time

## 🛠️ Customization

Edit `words.json` to add your own spelling lists:

```json
{
  "lists": [
    {
      "name": "Week 1",
      "words": ["apple", "banana", "orange"]
    }
  ]
}
```

## 🎨 Technologies

- Pure HTML5, CSS3, and vanilla JavaScript
- Web Speech API for text-to-speech
- LocalStorage for progress tracking
- Responsive design for all devices
